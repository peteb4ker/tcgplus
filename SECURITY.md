# Security

If you find a security issue in TCGPlus, please report it privately rather than opening a public GitHub issue.

The fastest way is GitHub's private vulnerability reporting: open the **Security** tab on this repository and click **Report a vulnerability**. If that's not available to you, email pete@skyetrail.com with details and (if you have one) a proof-of-concept.

We'll acknowledge within five business days and aim to ship a fix in the next release.

## Scope

- The published Chrome extension and its source in this repository.
- Anything that could let a TCGplayer page or another extension exfiltrate the user's session, leak data, or alter cart math.

Out of scope: vulnerabilities in TCGplayer itself or third-party browser extensions.
