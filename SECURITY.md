# Security

If you find a security problem in TCGPlus, please report it privately instead of opening a public GitHub issue.

The fastest way is GitHub's private vulnerability reporting: open this repository's **Security** tab and click **Report a vulnerability**. If that isn't available to you, email pete@skyetrail.com with the details and, if you have one, a proof of concept.

You'll get a reply within five business days, and we aim to ship a fix in the next release.

## Scope

- The published Chrome extension and its source in this repository.
- Anything that could let a TCGplayer page or another extension steal the user's session, leak data, or change the cart math.

Out of scope: vulnerabilities in TCGplayer itself or in other browser extensions.
